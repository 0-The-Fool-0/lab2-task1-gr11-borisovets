# Лабораторная работа № 2 — Максимальная сумма цифр в массиве (C)

[English version](README.md)

Небольшая консольная работа на языке C. Программа генерирует массив положительных псевдослучайных целых чисел, вычисляет сумму десятичных цифр каждого элемента и выводит все числа, у которых эта сумма максимальна.

## Сборка

Нужен C-компилятор с поддержкой C99, например GCC или Clang.

```bash
gcc -std=c99 -Wall -Wextra -Wpedantic src/main.c -o lab2-task1
```

## Запуск

Передайте желаемый размер массива единственным аргументом:

```bash
./lab2-task1 10
```

Программа генерирует числа от 1 до 1000. Поскольку значения случайны, результат меняется между запусками. Допустимый размер массива — от 1 до 1 000 000.

В Windows запустите исполняемый файл, созданный настроенным C-компилятором. Команда выше приведена для GCC/Clang.

## Алгоритм

1. Сгенерировать заданное количество положительных целых чисел.
2. Вычислить сумму цифр каждого элемента.
3. Найти максимальную сумму цифр.
4. Вывести все элементы с этой суммой.
